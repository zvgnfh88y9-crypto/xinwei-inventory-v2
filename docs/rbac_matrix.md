# 鑫威库存管理系统 v2.8 角色权限矩阵

| 功能模块 | 管理员 (admin) | 仓库主管 (inv_manager) | 员工 (staff) |
| :--- | :---: | :---: | :---: |
| **工作台概览** | 查看/所有指标 | 查看/所有指标 | 查看/仅基础指标 |
| **产品资料** | 新增/修改/删除 | 修改 | 仅查看 |
| **单据录入** | 全部类型 | 全部类型 | 仅入/出库申请 |
| **单据审核** | **拥有权** | **拥有权** | 无权限 |
| **财务入账 (Post)**| **拥有权** | **拥有权** | 无权限 |
| **红冲作废 (Void)**| **拥有权** | 无权限 | 无权限 |
| **报表导出** | 全部报表 | 仅库存报表 | 无权限 |
| **系统同步** | 全部权限 | 仅导入 | 无权限 |

> **注**：员工提交的单据默认为 `pending` 状态，必须经由管理员审核并点击“确认入账”后，库存数据才会真正发生增减变化。
