# 鑫威库存管理系统 v2.8 修改页面清单

## 1. 认证与安全
| 页面 | 变更内容 |
| :--- | :--- |
| **登录页 (`/login`)** | 增加 `admin`/`staff` 快速补全；实现**首次登录强制改密**拦截器；支持登录失败锁定逻辑。 |
| **系统中心 (`/sync`)** | 新增“安全审计”选项卡，实时展示全局敏感操作记录（入账、红冲、改价、开户）。 |

## 2. 核心业务工作台
| 页面 | 变更内容 |
| :--- | :--- |
| **控制台 (`/`)** | 后端 RPC 异步分析 36w 数据，前端增加 KPI 统计口径说明浮窗。 |
| **库存管理 (`/inventory`)** | **性能重构**：实现服务端分页（Page Size: 15），移除全表扫描。员工角色自动隐藏“成本价”字段。 |
| **业务流工作台** | 针对“入库、出库、调拨、盘点”实现**视觉色调隔离**。 |
| **单据详情模态框** | 增加“关联原单”溯源链；支持“红冲作废”一键生成对冲凭证。 |

## 3. 数据与报表
| 页面 | 变更内容 |
| :--- | :--- |
| **数据同步 (`/sync`)** | Excel 导入升级：支持**结构化错误明细表**预览与导出，精准定位 Excel 行号。 |
| **报表中心 (`/reports`)** | 新增库龄分析、周转率分析报表。 |
