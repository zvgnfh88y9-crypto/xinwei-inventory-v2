# 鑫威库存管理系统 v2.8 报表计算口径说明

## 1. 库存库龄分析 (Aging)
*   **计算公式**：`库龄 = 当前日期 - 产品首次入库日期`
*   **日期口径**：以 `inventory_products.created_at` 为基准。
*   **分段定义**：
    *   **新鲜 (<30天)**：快速流转物资。
    *   **常规 (30-90天)**：正常周转水平。
    *   **呆滞料 (>90天)**：需重点预警，防止库存积压。
*   **样例数据**：
    | SKU | 入库日期 | 物理库存 | 库龄 (天) | 类别 |
    | :--- | :--- | :--- | :--- | :--- |
    | XW-001 | 2026-05-01 | 100 | 97 | 呆滞料 |

## 2. 产品周转率分析 (Turnover)
*   **计算公式**：`周转率 = 统计期内总出库量 / 期末物理库存`
*   **统计周期**：默认为最近 30 天。
*   **筛选条件**：仅统计 `OUT` 类型的库存变动记录，且排除红冲对冲掉的数据。
*   **评价模型**：
    *   **高 (>2.0)**：产品极度畅销。
    *   **中 (0.5-2.0)**：正常业务节奏。
    *   **低 (<0.5)**：动销缓慢，建议优化生产或销售计划。

## 3. 空值与异常处理
*   **空库存**：周转率显示为 `0.00`，不参与平均值计算。
*   **负库存**：系统已从后端 RPC 层通过 `CHECK (stock >= 0)` 拦截，若历史数据存在负数，报表标记为“异常”。
